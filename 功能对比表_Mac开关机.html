📋 关键结论

  • 飞书只管"管道"：收发消息、渲染卡片、排队待处理。飞书不做任何 AI 出题/批改/错题本处理。
  • 所有智能能力依赖 Mac 开机：出题、批改、错题本、定时推送全部由本地 Python 程序 + DeepSeek API 完成。
  • Mac 关机 = 全部功能暂停：飞书消息会排队，但无人处理。开机后 bot_server 才能消费积压消息。
  • 周五关键窗口：周五 09:00 前必须开机，才能收到三天周末套餐。错过则需手动触发。
  • 如需 7×24 可用：考虑迁移到云服务器（已有 deploy.sh 脚本，支持一键部署到 Linux 云主机）。
💡 提示：如果你想让孩子即使在 Mac 关机时也能获得 AI 批改反馈，有两个方案：
① 云部署（执行 ./deploy.sh install 到云服务器）—— 彻底解决依赖 Mac 开机的问题；
② 保持 Mac 全天开机（当前方案）—— 简单但不稳定，适合大部分时间 Mac 在线的场景。
